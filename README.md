## 📌 Sobre o Projeto

Este é o meu **Portfólio Web (Versão 2.0)**, desenvolvido para apresentar minhas habilidades, projetos recentes, experiências e formas de contato. 

A aplicação foi planejada do zero com foco em **design moderno, responsividade, usabilidade e alta performance**, oferecendo uma navegação fluida e agradável tanto em dispositivos móveis quanto em desktops.

---

## ✨ Funcionalidades

- 📱 **Design 100% Responsivo:** Layout adaptável para smartphones, tablets e desktops.
- 🎨 **Interface Moderna & Clean:** Tipografia bem trabalhada, cores harmoniosas e componentes visuais elegantes.
- ⚡ **Animações & Interatividade:** Efeitos de hover, transições suaves de scroll e navegação dinâmica.
- 📂 **Seção de Projetos:** Destaque para as principais aplicações desenvolvidas, com links diretos para código e demonstrações.
- 🛠️ **Tech Stack & Skills:** Apresentação clara das tecnologias e ferramentas com as quais trabalho.
- 📬 **Contato Rápido:** Formulário e links diretos para redes sociais (LinkedIn, GitHub, E-mail).

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

- **HTML5:** Estruturação semântica do conteúdo.
- **CSS3:** Estilização, layout (Flexbox / CSS Grid), animações e media queries para responsividade.
- **JavaScript (ES6+):** Manipulação da DOM, interatividade e efeitos de navegação.
- **Git & GitHub:** Controle de versão e hospedagem contínua via **GitHub Pages**.
